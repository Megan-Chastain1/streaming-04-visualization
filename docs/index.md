## Custom Project

### Dataset

The dataset being used is sales information.

### Kafka Messages

Kafka is sending messages about item type/quantity, sales region, taxes, total amount.

### Consumer Processing

The consumer receives what the producer is sending.

### Experiments

I increased the producer max messages, producer message count,

and the producer intervals to see if that would increase the length of

the chart or result in any errors.

### Results

Nothing really changed.

### Interpretation

I understand that the workflow is sending and analyzing data in real time

and creating a chart to visualize it.
